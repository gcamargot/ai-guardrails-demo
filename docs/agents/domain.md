# Domain Docs

Before exploring or changing the project:

- Read the root `CONTEXT.md`.
- Read relevant ADRs under `docs/adr/`.
- Use the glossary's canonical vocabulary in tickets, tests and code.
- Avoid synonyms explicitly rejected by the glossary.
- Surface conflicts with existing ADRs instead of silently overriding them.

## Layout

This is a single-context project:

- `CONTEXT.md` contains domain terminology only.
- `docs/adr/` contains durable architectural decisions.
